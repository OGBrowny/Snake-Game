SNAKE GAME

Java Programming Project

Project Name: Snake Game
Programming Language: Java
GUI Framework: Java Swing
IDE: Visual Studio Code

1. Project Description

Snake Game is a simple graphical game developed using Java Swing. The player controls a snake that moves around the game board and eats apples to increase its length and score.

2. Features

- Graphical game interface
- Green snake and red apple graphics
- Keyboard movement controls
- WASD and arrow key support
- Automatic snake movement
- Apple eating and snake growth
- Score tracking
- Wall and self-collision detection
- Game over screen
- Restart and pause functionality
- Mouse event handling

3. Controls

- W / UP: Move Up
- A / LEFT: Move Left
- S / DOWN: Move Down
- D / RIGHT: Move Right
- P: Pause / Resume
- R: Restart after Game Over
- Mouse Click: Pause / Resume or Restart

4. Requirements

- Java Development Kit (JDK 21)
- Visual Studio Code or another Java IDE

5. How to Run

1. Open the project folder.
2. Open the terminal.
3. Compile using: javac SnakeGame.java
4. Run using: java SnakeGame

6. Concepts Used

- Classes and Objects
- Inheritance
- Arrays
- Loops and Conditional Statements
- Random Class
- Java Swing
- Graphics2D
- Event Handling
- Timer and ActionListener

7. Project Files

- SnakeGame.java – Main game source code
